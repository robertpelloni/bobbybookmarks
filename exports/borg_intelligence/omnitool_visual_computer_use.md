## 🧠 Technical Summary
A vision-based screen parsing and execution sandbox that turns screenshots into structured data for LLM-driven "Computer Use" interaction.

## 🛠️ Key Features
Two-step visual parsing (YOLOv8/Florence-2), high-accuracy icon/button detection, OmniBox dockerized Win11 sandbox, sub-second vision-to-action latency.
