## 🧠 Technical Summary
The `mcp-json-yaml-toml` project acts as a dedicated Message Communication Protocol (MCP) server, designed to bridge the gap between generalized AI agents (like Claude Code or Cursor) and structured configuration/data files. Its core innovation is providing a strict, schema-aware interface for data manipulation, contrasting sharply with unsafe regex/grep methods often employed by LLMs. It supports JSON, YAML, and TOML, leverages external tools like `yq` where necessary, and integrates novel features like schema discovery via directives (#:schema) and native support for LMQL constraints to validate inputs incrementally before tool execution. This local-first approach minimizes data exposure while maximizing the reliability of AI-driven file modifications.

## 🛠️ Key Features
Schema-aware structured data modification, JSON/YAML/TOML multi-format support, LMQL constraint integration for guided generation, Directive-based schema recognition, JSONC read support, Token-efficient data extraction, Local execution (Local-First principle).
