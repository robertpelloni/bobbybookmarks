## 🧠 Technical Summary
Nimbalyst functions as a session manager and visual editor, specifically tailored for enhancing interaction with AI code assistants like Claude Code and Codex. It provides a unified environment for editing markdown, CSVs, mockups (Excalidraw), architecture diagrams (Mermaid), and code. Key to its UX is 'side-by-side AI assistance,' allowing users to interact with the agents while visually editing content, with AI changes presented as inspectable diffs for approval. It emphasizes full-project awareness, visual data transformation in spreadsheets, and generating code directly from visual mockups, centralizing workflow away from context switching between multiple tools.

## 🛠️ Key Features
Visual file editing for multiple formats (Markdown, CSV, Code, Diagrams), Side-by-side AI interaction, Diff visualization and approval for AI edits, Visual UI planning/mockup to code generation, Session management with Kanban tracking, Full codebase context awareness for AI agents, Mobile application for session monitoring.
