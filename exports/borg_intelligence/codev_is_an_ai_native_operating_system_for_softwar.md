## 🧠 Technical Summary
Codev establishes a development methodology where natural language specifications within a project's context hierarchy (managed in the `codev/` directory) drive autonomous AI builders. It centers around the SPIR protocol (Specify, Plan, Implement, Review) which structures the interaction between human architects and specialized AI agents (builders) operating in an isolated 'Agent Farm'. This system aims to automate the feature delivery pipeline, from specification to merged PR, by managing multi-model consultation and ensuring decisions and context are version-controlled.

## 🛠️ Key Features
SPIR Protocol implementation, Agent Farm for parallel builders, Multi-model AI consultation, GitHub Issue to PR automation, Context hierarchy management, Version-controlled specifications and plans.
