## 🧠 Technical Summary
Maestro acts as a high-velocity orchestration layer that sits on top of existing agentic CLIs like Claude Code and OpenAI Codex. It innovates by using Git Worktrees to provide hardware-level process and file isolation for parallel agent tasks, allowing multiple agents to work on different branches of the same repository simultaneously. The system features an 'Auto Run' engine that processes markdown checklists as executable playbooks, maintaining clean context windows by spinning up fresh sessions for individual sub-tasks, and includes a moderator-led group chat for cross-agent coordination.

## 🛠️ Key Features
Git Worktree isolation, Markdown Playbook execution, Multi-agent group chat moderation, Mobile remote control via Cloudflare tunneling, Session discovery and resumption, Keyboard-first command palette, MCP tool pass-through, Real-time cost and token tracking
