## 🧠 Technical Summary
The AbanteAI/experiments GitHub repository serves as a public archive for the detailed artifacts generated during the inference and evaluation of AI models against the SWE-bench software engineering task. It standardizes the structure for storing predictions (all_preds.jsonl), evaluation results (results.json), execution logs (logs/*.log), and agent trajectories (trajs/*.traj) across different SWE-bench splits (dev, lite, test). The primary purpose is to enable transparent verification, reproducibility of results, and contribution to the official SWE-bench Leaderboard by providing clear submission guidelines.

## 🛠️ Key Features
SWE-bench evaluation artifact storage, standardized submission format for leaderboards, reproducible execution logging, public sharing of model inference data
