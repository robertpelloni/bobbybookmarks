# This project provides a Cloudflare Worker proxy that translates API calls between the Anthropic Claude API format and the Google Gemini API format.

## 🧠 Technical Summary
The gemini-router acts as a protocol translator situated between an application expecting an Anthropic API endpoint (like Claude Code) and the actual backend service (Google Gemini API). It intercepts requests formatted for Claude, converts them into the corresponding Google Gemini API request structure, forwards the request, and then translates the Gemini response back into the Anthropic format before sending it to the client. This enables compatibility for clients designed exclusively for one LLM provider to utilize another provider's models.

## 🛠️ Key Features
Anthropic API format acceptance, Conversion to Google Gemini API format, Translation of responses back to Anthropic format, Support for streaming and non-streaming responses, Cloudflare Worker deployment model
