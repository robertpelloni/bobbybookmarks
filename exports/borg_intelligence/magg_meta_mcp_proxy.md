## 🧠 Technical Summary
A meta-MCP server acting as a "package manager" that allows LLMs to autonomously discover, install, and orchestrate other MCP servers at runtime.

## 🛠️ Key Features
Runtime autonomous tool discovery, automatic prefix proxying (avoids conflicts), MCP sampling-based config generation, dual stdio/SSE support.
