## 🧠 Technical Summary
The Paper MCP Server acts as a standardized bridge between LLM-based assistants and Paper's financial trading API. By implementing the Model Context Protocol, it transforms traditional RESTful trading endpoints into a tool-set discoverable by AI agents. The server exposes specific functions for fetching real-time NBBO quotes, batching requests for multiple symbols, and executing various order types (market, limit, stop) within a simulated environment. It provides a blueprint for how financial platforms can expose complex transaction and data-retrieval workflows to coding assistants like Cursor and Claude via simple JSON configuration.

## 🛠️ Key Features
Real-time NBBO quote fetching, Batch quote retrieval, Simulated order execution (Market/Limit/Stop), Portfolio performance monitoring, P&L tracking, Cursor IDE integration, Claude Desktop support, Environment-based credential management
