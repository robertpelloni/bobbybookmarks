## 🧠 Technical Summary
This proposal introduces a standardized mechanism, the MCP Apps Extension (SEP-1865), to allow MCP servers to embed interactive user interfaces (UIs) within host applications. It addresses the current limitation where servers can only exchange text and structured data, which complicates use cases requiring visual presentation or complex user input gathering. The pattern involves declaring UI templates as resources with a `ui://` URI scheme, linking them to tool metadata, and using existing MCP JSON-RPC over `postMessage` for bidirectional communication within sandboxed iframes. Key design decisions prioritize security through sandboxing, pre-declaration of templates for host review, and auditable communication, while ensuring backward compatibility by requiring text-only fallbacks.

## 🛠️ Key Features
Standardized UI resource declaration, Tool metadata linkage for UI resources, JSON-RPC communication over postMessage for UI components, HTML rendering within sandboxed iframes, Security mitigation layers (sandboxing, pre-declaration, auditable messages).
