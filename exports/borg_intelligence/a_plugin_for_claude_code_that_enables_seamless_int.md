## 🧠 Technical Summary
This project implements a bridge between disparate LLM ecosystems by providing a set of 'skills' for the Claude Code CLI. It leverages the google-genai SDK to allow Claude to delegate specific tasks—such as high-fidelity image generation with search-grounded infographics and real-time web consultation—to Gemini 3 Pro. The technical approach uses 'uv' for inline dependency management, allowing the tools to be installed and executed with zero manual environment configuration. It demonstrates a practical implementation of model-to-model (A2A) collaboration where Claude acts as the primary orchestrator and Gemini serves as a specialized utility for vision, search-grounding, and image synthesis.

## 🛠️ Key Features
Cross-provider LLM orchestration, Google Search grounding for image synthesis, dynamic aspect ratio configuration, 'second-opinion' reasoning loops, zero-install dependency management via uv, multimodal vision integration for Claude, configurable thinking depth for Gemini sub-calls, automated context passing between providers.
