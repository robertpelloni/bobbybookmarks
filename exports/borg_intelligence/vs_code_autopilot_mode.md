## 🧠 Technical Summary
Introduced in VS Code 1.111, this mode allows GitHub Copilot to execute autonomously, continuously auto-approving tool calls and retrying errors to complete complex tasks.

## 🛠️ Key Features
Autonomous multi-step execution, auto-approval of tool calls, automated error retry loops, recommended use with Dev Containers/Terminal Sandboxing.
