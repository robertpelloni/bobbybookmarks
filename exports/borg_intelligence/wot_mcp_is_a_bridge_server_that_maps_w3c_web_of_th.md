# WoT-MCP is a bridge server that maps W3C Web of Things (WoT) device standards into Model Context Protocol (MCP) resources and tools, enabling AI agents to control physical IoT hardware.

## 🧠 Technical Summary
The project implements a technical translation layer that converts the standardized Web of Things model—comprising Properties, Actions, and Events—into MCP-compliant primitives. It offers two distinct tool strategies: an 'explicit' mode that creates granular, human-readable tools for every device capability, and a 'generic' mode providing a scalable set of four tools (list, read, write, invoke) for large-scale device management. By supporting HTTP, CoAP, and MQTT protocols, the server acts as a universal adapter, allowing any MCP client to discover and interact with physical sensors and actuators without custom device-specific logic.

## 🛠️ Key Features
WoT-to-MCP protocol translation, explicit tool generation strategy, generic tool management strategy, event buffering as resources, multi-protocol support (HTTP/CoAP/MQTT), streamable-http transport mode, dynamic configuration loading, Dockerized deployment
