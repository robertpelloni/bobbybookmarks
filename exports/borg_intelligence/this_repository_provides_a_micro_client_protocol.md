## 🧠 Technical Summary
The project implements a Python-based MCP server that interfaces with the Alternative.me API to fetch cryptocurrency Fear & Greed Index data. It defines specific endpoints (e.g., `fng://current`, `fng://history/{days}`) and corresponding tool functions (`get_current_fng_tool`, `get_historical_fng_tool`, `analyze_fng_trend`) that allow an MCP-compatible client (like Claude Desktop) to discover and invoke these functions to retrieve structured data, including historical analysis and interpretation prompts.

## 🛠️ Key Features
Real-time Index Retrieval, Historical Data Fetching, Trend Analysis, Tool-Only Support, MCP Endpoint Definition, Prompt Generation Template
