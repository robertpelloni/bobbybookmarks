# Switchboard is an AI agent proxy that aggregates multiple child MCPs into a single, token-efficient suite tool for a host.

## 🧠 Technical Summary
Switchboard acts as an intermediary layer, utilizing JSON-RPC over stdio to communicate with a host (like Claude Code or Cursor). It discovers and manages numerous specialized Model Context Providers (MCPs) by spawning them on demand (lazy loading). The core innovation is aggregating the tools exposed by these many child MCPs into a single, cohesive suite tool presented to the host, drastically reducing the context window overhead (85-90% token reduction) by only exposing subtools when explicitly requested via introspection.

## 🛠️ Key Features
Token reduction via lazy subtool expansion, Aggregation of multiple MCPs into one suite tool, On-demand child MCP spawning, Auto-migration and discovery of existing MCP configurations, JSON-RPC based communication layer.
