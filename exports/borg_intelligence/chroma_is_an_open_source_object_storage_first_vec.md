## 🧠 Technical Summary
Chroma provides a specialized persistence layer for AI applications, optimizing for both cost and performance by leveraging an object-storage-centric architecture (S3/GCS) rather than purely memory-bound indexing. It employs a three-tier intelligent data strategy—caching hot data in memory, warm data on SSD, and cold data on object storage—to achieve up to 10x cost reductions while maintaining low-latency search over billions of records. Its core engine, written in Rust, supports hybrid search capabilities including dense vector similarity, sparse lexical search (BM25/SPLADE), regex, and metadata filtering, alongside unique developer features like copy-on-write collection forking for A/B testing.

## 🛠️ Key Features
Vector similarity search, Sparse vector search (BM25/SPLADE), Trigram and regex search, Metadata filtering, Collection forking (copy-on-write), Automatic data tiering, Chroma Sync (automated ingestion), Multi-tenant indexing
