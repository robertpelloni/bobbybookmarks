# Zypher Agent implements Programmatic Tool Calling (PTC) using a sandboxed Deno runtime to offload repetitive tool orchestration from the LLM context to executed code.

## 🧠 Technical Summary
The technical approach shifts the paradigm of tool interaction from sequential LLM-driven calls to programmatic execution. When an agent identifies a data-intensive task, it generates TypeScript code that executes within an isolated Deno WebWorker sandbox. This worker communicates via a custom JSON-RPC protocol with a Main Thread Controller to access MCP (Model Context Protocol) tools. By processing logic locally and returning only a summary to the LLM, the system achieves an 85-98% reduction in token usage. The implementation also introduces a granular 'allowed_callers' security property, enabling developers to restrict specific tools to either the LLM, the code runner, or both, preventing model confusion and improving safety.
