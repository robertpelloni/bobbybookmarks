## 🧠 Technical Summary
Serena acts as a layer between Large Language Models (LLMs)/coding agents and the codebase, offering IDE-like tools such as semantic code retrieval and symbol-level editing. Its core interoperability mechanism is the Model Context Protocol (MCP) server, which allows various LLM clients (like Claude Code, Cursor, Gemini-CLI, OpenWebUI) to interact with Serena's codebase understanding tools. It supports two primary backends for semantic analysis: Language Server Protocol (LSP) for broad language support and a dedicated JetBrains Plugin for deeper IDE integration.

## 🛠️ Key Features
Model Context Protocol (MCP) Server implementation, Semantic code retrieval at the symbol level, Code entity extraction and relational structure exploitation, LSP integration for broad language support (>30 languages), JetBrains Plugin for deep IDE integration, Decoupled tool implementation adaptable to various agent frameworks
