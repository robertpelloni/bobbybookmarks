## 🧠 Technical Summary
Resterm is a high-performance Terminal User Interface (TUI) designed for API interaction and debugging without cloud dependencies. It treats requests as plain-text files (.http/.rest), enabling version control and local persistence. The tool integrates advanced connectivity features directly into the client, including native SSH tunneling and Kubernetes port-forwarding. It utilizes a custom expression language called RestermScript for dynamic variable capture, assertions, and conditional logic. The architecture supports multi-step workflows, response diffing, and real-time profiling, providing a unified environment for developers to test complex API lifecycles entirely within the terminal.

## 🛠️ Key Features
Plain-text request definitions, native Kubernetes port-forwarding, integrated SSH tunneling, RestermScript expression language, multi-step workflow orchestration, gRPC and WebSocket support, environment variable isolation, response history and diffing
