## 🧠 Technical Summary
TabCrunch leverages large language models to process browser state and transform high-volume tab sessions into structured research data. The tool focuses on 'crunching' information by generating concise summaries of active tabs, calculating estimated reading times, and identifying content overlap between different sources to reduce redundancy. By providing a centralized interface for tab metadata and keyword-based retrieval, it aims to solve the 'tab clutter' problem while facilitating collaborative research through sharable tab groups.

## 🛠️ Key Features
AI-driven tab summarization, content overlap detection, automated tab grouping, reading time estimation, cross-tab keyword search, collaborative tab group sharing, memory optimization via tab suspension
