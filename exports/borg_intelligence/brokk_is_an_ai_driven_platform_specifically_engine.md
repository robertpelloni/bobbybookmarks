## 🧠 Technical Summary
Brokk addresses the 'lost in the middle' and context window limitation problems inherent in large-scale software development. It utilizes advanced repository indexing and semantic search to map out complex cross-file dependencies and architectural patterns. By combining static analysis with Retrieval-Augmented Generation (RAG), it allows developers to query entire repositories, providing the LLM with highly relevant, isolated context snippets that maintain structural accuracy without exceeding token limits. This approach focuses on the engineering of codebase context as a first-class citizen for AI interaction.

## 🛠️ Key Features
Semantic codebase indexing, cross-file dependency mapping, automated context pruning, repository-level natural language Q&A, intelligent code snippet retrieval, architectural pattern recognition, multi-repository support
