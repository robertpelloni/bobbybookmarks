## 🧠 Technical Summary
A Google-originated protocol that shifts UI implementation from the agent to the client, using declarative JSON blueprints to ensure security and XSS resistance.

## 🛠️ Key Features
JSON-based UI intent blueprints, intent-implementation separation, native renderer-agnostic display, built-in session/auth inheritance.
