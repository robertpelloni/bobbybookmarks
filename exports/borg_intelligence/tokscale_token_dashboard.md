## 🧠 Technical Summary
A TUI-based token tracking dashboard for OpenCode and Claude Code that provides real-time visualization of input/output tokens and session costs.

## 🛠️ Key Features
Real-time TUI dashboard, 2D/3D token contribution graphs, cost estimation via LiteLLM, cross-tool support (Claude/Gemini/Cursor).
