## 🧠 Technical Summary
This guide details the construction of Orchestrator Agents within the OpenCode ecosystem, emphasizing a 'Router, Not Executor' architecture. It establishes a strict security model through YAML frontmatter that disables write and bash capabilities while enabling read-only context tools and a core 'task' tool for delegation. The technical approach focuses on capability mapping, where user requests are matched against a defined set of subagents, and supports advanced orchestration patterns including sequential chaining (passing output from one agent to the next) and parallelization (issuing multiple task tool calls simultaneously). It also introduces a 'Context First' discovery pattern to ensure subagents receive high-quality, relevant project data.

## 🛠️ Key Features
Deterministic routing logic, parallel subagent delegation, sequential task chaining, capability mapping tables, context-first discovery patterns, YAML-based tool restriction, standardized response formatting, prompt engineering for stateless subagents, token management via high-level overview tools.
