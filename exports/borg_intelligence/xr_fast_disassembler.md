## 🧠 Technical Summary
An ultra-fast, Rust-based CLI tool designed for parallel extraction of cross-references from stripped binaries, significantly outperforming traditional disassemblers.

## 🛠️ Key Features
Parallel cross-reference extraction (from_va, to_va), ELF/Mach-O/PE support, linear/paired scanning modes, native Claude Code skill integration.
