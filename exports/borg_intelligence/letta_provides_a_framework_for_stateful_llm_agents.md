## 🧠 Technical Summary
Letta’s architecture implements a tiered memory system that treats the LLM's context window as a volatile cache while maintaining a complete source of truth in a backing database. It introduces 'Memory Blocks'—discrete, editable segments of context that are pinned to the system prompt—allowing agents to programmatically update their own 'core' beliefs and facts via tool calls. The system handles context overflow through automated compaction and provides mechanisms for archival memory retrieval, ensuring that reasoning, tool outputs, and historical messages remain accessible even after they are evicted from the active context window.

## 🛠️ Key Features
Persistent Memory Blocks, Self-editing memory tools, Context window compaction, Archival memory retrieval, Shared memory blocks across agents, Run/Step execution tracking, Conversation thread isolation, Tiered context hierarchy
