## 🧠 Technical Summary
The technical approach involves a multi-stage agent workflow orchestrated by a 'GPT Builder' agent. First, candidate tools (in this case, separate Wikipedia query engines for different cities) are defined and indexed using an ObjectIndex/ToolRetriever. The GPT Builder then utilizes three core internal tools: one to generate a task-specific system prompt (using GPT-4), another to retrieve the necessary tools based on the task, and a third to instantiate the final FunctionAgent using the generated prompt and selected tools. This meta-level orchestration allows for the creation of specialized agents on demand based on a high-level user request.
