## 🧠 Technical Summary
The wot-mcp-cli provides a specialized interface for developers to interact with IoT devices that are exposed through an MCP-compliant server. It supports both local stdio transport and remote streamable-HTTP transport, allowing for flexible deployment scenarios. The tool interprets MCP tool and resource definitions, providing a shell-like environment where users can execute device actions using JSON arguments and manage data streams via a URI-based subscription model. This project is critical for testing the bridge between Large Language Model context windows and physical hardware standardized under the W3C Web of Things architecture.

## 🛠️ Key Features
Interactive MCP shell, stdio transport support, streamable-http transport support, dynamic tool schema inspection, JSON-based tool execution, URI-based resource discovery, real-time resource subscription, WoT property reading
