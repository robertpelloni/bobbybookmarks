## 🧠 Technical Summary
Kode-Agent functions as a powerful command-line interface (CLI) AI assistant capable of understanding codebases, editing files, running shell commands, and automating workflows. It supports an 'AGENTS.md' standard for instruction discovery across the project structure, enabling delegation to specialized subagents via commands like '@run-agent-name'. The system employs a multi-model collaboration framework, allowing users to consult different AI models for specialized tasks. A key architectural decision is the default YOLO (You Only Live Once) mode, which bypasses permission checks for maximum productivity, though a `--safe` mode is available for manual approval. The agent orchestrates actions based on context discovered from the project structure and documentation standards.

## 🛠️ Key Features
AGENTS.md standard support, Subagent System for delegation, Multi-Model Collaboration, Command Execution via AI prompt, YOLO/Safe Mode for permissions, Interactive terminal UI, Codebase Understanding.
