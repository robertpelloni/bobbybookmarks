## 🧠 Technical Summary
A specialized open-source engine fork of OpenClaw that modernizes the classic game with high-refresh rate decoupling and a built-in Lua scripting engine.

## 🛠️ Key Features
Decoupled frame/tick rate logic (144Hz support), Lua-based advanced scripting engine, live asset hot-reloading (.pid/.wag), integrated Level Editor mode.
