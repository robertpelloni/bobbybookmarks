## 🧠 Technical Summary
The project implements the Model Context Protocol (MCP) using the Python SDK to expose CryptoPanic's cryptocurrency news aggregation services to LLM-based agents. It defines a specific tool schema, 'get_crypto_news', which allows agents to query news items with parameters for content type (news vs. media) and pagination depth (up to 10 pages). The server manages API authentication and plan-level logic via environment variables, transforming external financial data into a format optimized for LLM context windows, thereby enabling agents to perform real-time market analysis.

## 🛠️ Key Features
MCP tool implementation, CryptoPanic API integration, multi-page data fetching, content type filtering (news/media), automated environment isolation via uv, real-time cryptocurrency news stream, API plan level support
