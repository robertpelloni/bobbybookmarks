# An MCP server that enables AI agents to delegate complex coding tasks to Anthropic's Claude Code CLI by running it in a non-interactive, permission-bypassed mode.

## 🧠 Technical Summary
This project acts as a bridge between the Model Context Protocol (MCP) and Anthropic’s Claude Code CLI tool, facilitating an 'agent-within-an-agent' workflow. It wraps the Claude Code binary into a single MCP tool called claude_code, which executes prompts using the --dangerously-skip-permissions flag to bypass interactive prompts. This allows higher-level agents (like Cursor, Windsurf, or Claude Desktop) to offload complex, multi-step file operations and terminal commands to a specialized agent that possesses higher autonomy and better context management for deep code edits. The implementation leverages Node.js to manage the CLI lifecycle and provides a mechanism for environments like Cursor to overcome their native limitations in file system manipulation.

## 🛠️ Key Features
One-shot Claude Code execution, MCP-compliant tool interface, Automated permission bypass, Agent-to-agent delegation, Support for custom Claude CLI binaries, Non-interactive file refactoring, Multi-command queuing, IDE integration for Cursor and Windsurf
