## 🧠 Technical Summary
A local Zig-based service router that eliminates Docker port conflicts by assigning "pretty" local URLs and routing traffic without exposing host ports.

## 🛠️ Key Features
Zero-config automatic port assignment, `<service>.<project>.localhost` routing, parallel git worktree support (isolated instances), SO_REUSEPORT multi-process proxy.
