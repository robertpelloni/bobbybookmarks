## 🧠 Technical Summary
Amped addresses the specific developer friction of account management within CLI-based AI agents. It functions by programmatically swapping the underlying credential files and system keychain entries required by Amp and Claude Code. For Amp, it manages the ~/.local/share/amp/secrets.json file; for Claude Code, it handles OS-specific credential paths and merges configuration data back into active JSON profiles. The tool utilizes the system keyring to ensure secrets are stored securely rather than in plain text, providing a streamlined workflow for developers who must navigate between different organizational identities, billing accounts, or sandbox environments.

## 🛠️ Key Features
Secure system keyring integration, automated configuration file merging, multi-service support (Amp/Claude Code), persistent state tracking, cross-platform credential handling (Linux/macOS), account status visualization
