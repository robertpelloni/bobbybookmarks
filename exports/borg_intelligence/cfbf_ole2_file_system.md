## 🧠 Technical Summary
A legacy sector-based binary format ("file system within a file") used for MSI, older Office docs, and proprietary industrial data.

## 🛠️ Key Features
Hierarchical Storage/Stream objects, sector-based FAT allocation, MiniFAT for small data, 2GB v3 size limit.
