## 🧠 Technical Summary
A utility that allows users to extract and replace the default "spinner" processing verbs in Claude Code (e.g., changing "Thinking" to "Cooking").

## 🛠️ Key Features
Replaces default processing verbs, modifies `~/.claude/settings.json`, native language (e.g., Korean) translation support.
