## 🧠 Technical Summary
mcpproxy acts as a crucial middleware layer for Model Context Protocol (MCP) interactions, specifically designed to connect an AI agent to several backend MCP servers. Its core functionality involves dynamic tool discovery across these federated servers, intelligent indexing of available tools using configurable embedding backends (like BM25, HuggingFace, or OpenAI), and providing a unified interface for the agent. It supports two main routing strategies: DYNAMIC mode, which registers discovered tools on-demand via MCP notifications, and CALL_TOOL mode, which executes tools through the proxy without dynamic registration, ensuring compliance with the MCP specification.

## 🛠️ Key Features
Dynamic Tool Discovery, Intelligent Tool Search (Embedding Backends), Flexible Routing Strategies (DYNAMIC/CALL_TOOL), MCP Specification Compliance, Persistent Indexing (SQLite + Faiss), Output Truncation for Context Management, FastMCP v2 Integration.
