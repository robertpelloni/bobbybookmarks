## 🧠 Technical Summary
An open-source AI web automation SDK by Browserbase that acts as a resilient, self-healing alternative to Playwright by using LLMs to navigate without brittle CSS selectors.

## 🛠️ Key Features
Self-healing UI navigation (no CSS selectors), AI primitives (`act`/`extract`/`observe`), CDP direct-browser communication (v3), Accessibility Tree extraction.
