## 🧠 Technical Summary
A vision-based framework that enables multimodal models to control a computer by viewing screenshots and generating high-accuracy XY click actions.

## 🛠️ Key Features
High-accuracy XY coordinate clicking (Agent-1-Vision), human-in-the-loop permission mode, hybrid Vision/OCR navigation, cross-platform Python drivers.
