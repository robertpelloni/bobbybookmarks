## 🧠 Technical Summary
This project leverages Python scripts and GitHub Actions to programmatically fetch data from the GitHub GraphQL API, calculating comprehensive developer metrics that exceed standard platform displays. It specifically tracks total lines of code contributed across a user's entire history and generates dynamically updated SVG assets for both light and dark modes, providing a personalized, real-time data dashboard for developer identity and proof of work.

## 🛠️ Key Features
GitHub GraphQL API integration, automated metrics calculation, dynamic SVG generation, scheduled GitHub Actions workflows, cross-repository code line counting, dark/light mode optimization
