## 🧠 Technical Summary
Étoilé seeks to replace the traditional file/process-centric user interface with one centered on user activities. Key technical aspirations include universal revision history for all system objects, seamless collaboration across all document types (text, code, drawing), and a customizable workflow achieved via combinable 'Services.' The project emphasizes a user experience closer to the user's mental model by abstracting away low-level implementation details like files and operating-system processes. It is built using GNUstep, suggesting a focus on cross-platform compatibility using Objective-C/Smalltalk paradigms.

## 🛠️ Key Features
