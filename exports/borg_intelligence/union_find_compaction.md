## 🧠 Technical Summary
A graph-based context management algorithm that replaces flat summarization with a recoverable "Union-Find" tree structure to eliminate batch-stall latency.

## 🛠️ Key Features
O(1) incremental message compaction, `expand(root_id)` lossless summary reinflation, graph-based message provenance tracking, multi-user shared memory support.
