## 🧠 Technical Summary
This project implements a middleware proxy server designed specifically for the Model Context Protocol (MCP) ecosystem. It centralizes connections, manages tool/prompt discovery, and intelligently routes client requests (from clients like Claude Desktop, Cline, Cursor) to various underlying MCP servers using either STDIO or Streamable HTTP transport. It effectively creates a 'Crossroads for AI Data Exchanges' by unifying knowledge (RAG v2), memory, and tools under a single interface, abstracting the complexity of multiple backend servers for the client.

## 🛠️ Key Features
Unified MCP aggregation, Proxy functionality for STDIO/Streamable HTTP, Centralized tool/resource discovery, AI Document Exchange (RAG v2) integration, Persistent AI Memory integration, Multi-server support, Dual transport modes (STDIO/HTTP).
