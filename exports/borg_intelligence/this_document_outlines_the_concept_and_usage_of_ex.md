## 🧠 Technical Summary
The resource details the Gemini CLI extension system, which standardizes how users can enhance the CLI's functionality by packaging components such as prompts, MCP servers, custom commands, themes, hooks, sub-agents, and agent skills into easily shareable units. It provides guidance for both consuming extensions (discovering, installing, and listing them via `/extensions` command or `gemini extensions` group) and building/publishing new ones, focusing heavily on the user experience of expanding the CLI's capabilities.

## 🛠️ Key Features
Extension packaging (prompts, MCP servers, commands, hooks), Interactive CLI management (/extensions), Terminal-based extension management (gemini extensions group), Extension installation via GitHub URL, Extension building guides.
