## 🧠 Technical Summary
The AnythingLLM Custom Agent Skill Developer Guide details the requirements and structure necessary for extending an agent's capabilities through custom skills. Skills must be written in JavaScript, execute in a NodeJS environment, and adhere to specific structural rules: a root `README.md`, a mandatory `plugin.json` defining metadata and the entry point (`handler.js`), and the skill folder name must match the `hubId` in `plugin.json`. The guide specifies where these skill folders must be placed within the AnythingLLM storage directory, which varies based on deployment (Docker, local, desktop). It also notes support for hot-loading changes and emphasizes that all function outputs must return a string.

## 🛠️ Key Features
Custom NodeJS execution environment for skills, plugin.json schema for skill definition, strict input/output contract (string return values), skill hot-reloading capability, standardized storage location for plugins.
