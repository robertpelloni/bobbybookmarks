## 🧠 Technical Summary
The AgentController implements a sophisticated state-machine and event-driven loop that governs how agents interact with their environment. It manages the transition between actions and observations, tracks task budgets and iteration limits, and includes a built-in 'StuckDetector' to identify and resolve infinite loops. A key technical feature is its support for recursive delegation, where a parent controller can spawn child controllers to handle sub-tasks, maintaining a hierarchy of state and LLM configurations while communicating via an asynchronous event stream.

## 🛠️ Key Features
recursive agent delegation, event-stream based orchestration, automated loop/stuck detection, budget-limited task execution, state-aware traffic control (pause/resume), robust error recovery for runtime crashes
