# This project implements a mechanism within Claude Code to route requests to various external Large Language Models (LLMs) hosted via the OpenRouter intermediary service.

## 🧠 Technical Summary
The repository provides a shell script-based system that integrates with Claude Code's ability to call external tools. When a user prompt within Claude Code mentions a specific LLM name (e.g., 'Use kimi to write...'), a pre-configured agent setup (defined in `.claude/agents/external-llm.md`) triggers an external call orchestrated by the provided `openrouter.sh` script. This script fetches the user query, specified model ID, and optional context/output path, formats the request according to the OpenRouter API specifications, executes it using the user's OpenRouter API key, and handles saving the result to a specified file location. It effectively bridges the native Claude environment with a multitude of third-party models via a standardized proxy layer (OpenRouter).

## 🛠️ Key Features
External LLM routing via prompt mention, OpenRouter API integration, configurable model mapping (models.conf), direct CLI execution for testing, context file inclusion, custom output path specification.
