# An MCP server that enables real-time human-in-the-loop feedback for AI agents through a file-based synchronization mechanism in the local workspace.

## 🧠 Technical Summary
TaskSync MCP implements a specialized state-management workflow where an agent is programmatically bound to a continuous feedback loop using a dedicated workspace file (feedback.md). The server provides a 'get_feedback' tool that leverages a file watcher and configurable timeouts to pause agent execution until a user provides manual input, effectively creating a persistent synchronization bridge between user intent and agent action. This approach forces an iterative development cycle by mandating the agent check for updated instructions after every task, supported by supplementary tools for media inspection to allow the agent to verify UI/UX changes in real-time.

## 🛠️ Key Features
Human-in-the-loop synchronization, file-based command bridging, real-time workspace file watching, configurable agent timeout logic, automated feedback file lifecycle management, base64 media streaming for visual verification, mandatory loop-based agent instructions.
