## 🧠 Technical Summary
AI Tab Grouper is a Firefox-based productivity tool that automates workspace organization by processing browser tab metadata through an LLM. The technical implementation involves extracting active tab titles and URLs via the WebExtensions API, passing this structured context to an OpenAI-compatible endpoint, and executing grouping commands based on the model's semantic classification. It follows a 'Bring Your Own Key' (BYOK) architecture, allowing users to maintain control over their API usage and costs while integrating AI directly into the browser's native tab management interface.

## 🛠️ Key Features
Semantic tab categorization, OpenAI API integration, native browser tab group manipulation, Bring Your Own Key (BYOK) support, metadata-based context extraction, custom subject-based grouping
