## 🧠 Technical Summary
Tether-Chat implements a recursive memory management architecture designed to overcome the context window limitations of standard LLMs. It operates by partitioning interaction data into two distinct layers: an 'active journal' containing recent verbatim exchanges and a 'memory journal' containing condensed reflections. When the active journal reaches a predefined token threshold, the oldest entries are programmatically sent to the LLM for summarization and curation before being integrated into the long-term memory journal. This sliding-window approach allows the model to retain critical historical context and identity continuity while ensuring the prompt remains within the model's hardware or API constraints.

## 🛠️ Key Features
Rolling context management, threshold-based summarization, dual-tier memory architecture (verbatim vs. curated), local-first persistent storage, multi-provider LLM support (OpenAI, Google AI, DeepSeek), C++/Qt cross-platform framework integration.
