# This SDK introduces Programmatic Tool Calling (PTC) to drastically reduce LLM inference costs and latency by replacing sequential tool calls with generated, sandboxed JavaScript execution.

## 🧠 Technical Summary
The core innovation is transforming multi-round-trip tool invocation, common in traditional LLM applications, into a single round-trip process. The LLM generates a complete JavaScript snippet that orchestrates multiple tool calls in parallel (using `Promise.all` semantics) based on defined tool schemas (Zod/JSON). This generated code is then executed within a secure, isolated Vercel Sandbox environment. The result of the entire orchestration is returned to the LLM in one step, preventing intermediate results from polluting the context window, leading to documented 80% token savings and 3-5x latency improvements. It specifically features an MCP Bridge for integrating external Model Context Protocol services.

## 🛠️ Key Features
Programmatic Code Generation for Tools, Vercel Sandbox Execution, Universal Model Support via AI SDK/Gateway, MCP Protocol Integration (HTTP/SSE/Stdio), Defensive Runtime Helpers, Parallel Tool Execution Logic.
