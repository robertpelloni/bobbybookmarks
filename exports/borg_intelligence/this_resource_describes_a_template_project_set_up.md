## 🧠 Technical Summary
The repository 'qa-party' is a boilerplate setup generated by the 'mentat-template-js' template, designed to integrate the Mentat AI coding assistant into a standard development lifecycle. The core functionality revolves around using Mentat to automate or assist with tasks such as setting up a new repository, handling issues tagged with '@MentatBot', reviewing pull requests, and interacting with the project via a dedicated website chat interface. It defines the workflow for onboarding a new project into the Mentat ecosystem, thereby establishing an AI-driven layer over standard Git/GitHub operations.
