## 🧠 Technical Summary
The core technical achievement described is enabling browser-based access to command-line exposed coding agent SDKs by implementing significant proxy and relay infrastructure. This involves an ACP-over-WebSockets proxy to handle standard I/O communication between the browser and external agents, acting as a PubSub system. Furthermore, to allow agents to leverage browser functionality (like contextual testing) which usually requires the Model Context Protocol (MCP), Tidewave implemented an MCP-over-WebSockets relay, allowing the browser to function as an MCP server via WebSocket I/O.

## 🛠️ Key Features
Agent SDK invocation from browser, ACP-over-WebSockets proxy, PubSub system for agent communication, MCP-over-WebSockets relay for browser context sharing, Deep web framework integration (documentation, logs, DB access).
