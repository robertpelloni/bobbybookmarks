## 🧠 Technical Summary
The Pieces CLI Agent acts as a terminal-centric bridge to the Pieces OS ecosystem, focusing on high-velocity developer workflows. It provides a structured command set for CRUD operations on code assets, sophisticated context-injection for LLM queries using local files and existing snippets, and integrated git workflow automation. Technically, the project emphasizes UX through shell auto-completion for multiple shells (Bash, Zsh, Fish, PowerShell), a persistent interactive 'run' mode to reduce command overhead, and multi-modal search capabilities including fuzzy, full-text, and neural code search (NCS).

## 🛠️ Key Features
Interactive loop mode, neural code search, context-aware AI querying, shell auto-completion, git commit message automation, snippet management, local/cloud model switching, asset-based context injection
