# AgentExport is a tool for securely sharing and persisting encrypted transcripts from AI coding environments like Claude Code or Codex.

## 🧠 Technical Summary
AgentExport functions as an end-to-end encrypted sharing utility for AI interaction transcripts. Encryption (AES-256-GCM) and compression occur locally on the client side before opaque blobs are uploaded to the server. Decryption is performed entirely in the recipient's browser using a key embedded in the URL fragment (#key), ensuring the server operator cannot access the plaintext content. Transcripts have a configurable auto-expiration time (default 30 days) and support persistence via self-hosting on Cloudflare Workers/R2 or using GitHub Gists as an alternative backend.

## 🛠️ Key Features
Client-side AES-256-GCM encryption, Decryption key in URL fragment, Configurable time-to-live (TTL), Self-hosting options (Cloudflare Workers/R2), GitHub Gist backend support, Command-line integration for coding assistants.
