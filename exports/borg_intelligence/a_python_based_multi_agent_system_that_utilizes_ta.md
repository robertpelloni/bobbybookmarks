## 🧠 Technical Summary
The system implements a multi-phase orchestration pattern consisting of analysis, sharding, parallel resolution, and final consolidation. It utilizes a state-management architecture using a JSON-based state file with atomic file locking to prevent race conditions during parallel sub-agent updates. The orchestration logic generates a structured Markdown instruction file (amp_instructions.md) which serves as a prompt-based execution plan for the Amp AI extension, demonstrating a hybrid approach between traditional script-based coordination and human-in-the-loop AI orchestration. Key technical highlights include a deterministic-to-probabilistic fallback mechanism where agents query the FinnHub API before falling back to OpenAI GPT-4 for symbol resolution.
