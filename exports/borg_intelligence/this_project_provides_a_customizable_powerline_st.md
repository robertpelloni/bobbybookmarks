## 🧠 Technical Summary
The `claude-limitline` tool integrates directly into the Claude Code IDE environment by reading configuration from `stdin` (hook data) and polling Anthropic's OAuth usage API to fetch current 5-hour block and 7-day rolling usage limits. It renders this information, along with Git branch details and the active Claude model, in a visually rich, segmented status line supporting multiple themes and Nerd Fonts. Configuration allows deep customization of segment ordering, display style (text vs. bar), polling intervals, and responsiveness to terminal width (compact mode). It securely retrieves the necessary OAuth token from platform-specific credential stores (Keychain, Credential Manager).

## 🛠️ Key Features
Real-time Claude usage limit display, Powerline-style segmented status bar, Git branch integration with dirty status, Customizable segment order, Multiple color themes, Secure OAuth token retrieval, Debugging mode for troubleshooting.
