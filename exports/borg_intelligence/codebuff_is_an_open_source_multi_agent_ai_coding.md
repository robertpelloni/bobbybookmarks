## 🧠 Technical Summary
Codebuff utilizes a modular multi-agent architecture to handle complex software engineering tasks by decomposing them into specialized roles including File Pickers for context retrieval, Planners for sequencing, Editors for code generation, and Reviewers for validation. Its technical core allows for high customization through TypeScript-based agent definitions, enabling developers to programmatically control agent behavior, branch on conditions, and spawn sub-agents. By integrating with OpenRouter, it maintains model agnosticism, allowing users to swap between various LLMs like Claude, GPT-4o, and DeepSeek depending on the specific task requirements.

## 🛠️ Key Features
Multi-agent task decomposition, TypeScript agent generators, OpenRouter model flexibility, Integrated SDK for production workflows, Automated terminal command execution, Specialized File Picker agent, Reviewer-driven validation loops, Custom tool and sub-agent spawning
