# Sem-Mem provides a local, tiered semantic memory solution for AI agents using an HNSW index for disk persistence and an LRU cache for fast recall.

## 🧠 Technical Summary
Sem-Mem implements a hybrid, two-tiered memory architecture designed for local deployment of AI agents. Tier 1 (L1, SmartCache in RAM) uses a segmented LRU cache for frequently or recently accessed memories, enabling near-zero-latency recall. Tier 2 (L2, Disk-backed) utilizes an HNSW index via `hnswlib` for persistent, long-term storage, combined with a lexical index to handle exact identifier matches missed by pure vector search. Retrieval involves merging vector similarity scores (weighted at 0.7) and lexical scores (weighted at 0.3), applying time-decay scoring, and factoring in outcome utility before promoting hits to L1. It explicitly trades horizontal scalability for simplicity, low operational overhead, and local control, making it suitable for personal assistants or small-team agents not requiring external, managed vector databases.
