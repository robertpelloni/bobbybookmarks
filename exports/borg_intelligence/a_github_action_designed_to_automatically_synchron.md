## 🧠 Technical Summary
MemVault Sync functions as a bridge between version control systems and AI memory layers by automating the ingestion of Markdown and source code into a long-term knowledge graph. The tool utilizes TypeScript and GitHub Actions to intercept push events, filter files via glob patterns, and transmit content to the MemVault API. This ensures that RAG (Retrieval-Augmented Generation) systems and AI agents have access to the latest repository context without manual re-indexing, effectively treating the codebase as a live-updating persistent memory source.

## 🛠️ Key Features
CI/CD memory synchronization, glob-pattern file filtering, multi-vault support, custom API endpoint configuration, automatic documentation indexing, push-triggered context updates
