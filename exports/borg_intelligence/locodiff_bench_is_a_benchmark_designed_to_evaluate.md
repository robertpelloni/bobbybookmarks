## 🧠 Technical Summary
The LoCoDiff-bench repository provides a framework for evaluating Language Models (LLMs) on tasks requiring long-context understanding of code evolution, specifically mimicking the process of tracking changes across a Git history. It focuses on using naturally interconnected content derived from actual Git repositories, ensuring that all contextual information provided is relevant to the task (no 'junk context'). This directly tests an LLM's capacity for state tracking over extended sequential inputs, which is crucial for coding agents that need to manage complex, multi-file edits over time. The benchmark emphasizes generating long-form outputs and is designed to be procedurally generated from any Git repository file.

## 🛠️ Key Features
Natural Git history evaluation, No junk context methodology, Long-form output testing, Procedural benchmark generation from any Git repository, Simple prompt/output evaluation structure.
