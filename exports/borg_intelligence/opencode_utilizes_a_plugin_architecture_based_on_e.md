## 🧠 Technical Summary
The OpenCode documentation details a robust plugin system that allows for significant customization of the application's behavior. Plugins can be loaded from local directories or npm packages, with a defined loading order that prioritizes project configuration over global settings. Developers can extend OpenCode by subscribing to a comprehensive list of events (e.g., file changes, tool execution, session updates) via exported functions within their plugin module. These functions receive a context object providing access to core components like the project state, an SDK client for AI interaction, and shell execution APIs. Key functionalities include environment variable injection, custom tool definition using a schema-based approach, system notification sending, and modification of the session compaction process. TypeScript support and structured logging via `client.app.log()` are also integral parts of this extensibility framework.
