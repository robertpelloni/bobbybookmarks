## 🧠 Technical Summary
A CLI manager that treats generative AI prompts as runnable, programmable commands, allowing `.prompt` files to accept arguments and stdin/stdout piping.

## 🛠️ Key Features
Treats `.prompt` files as native CLI commands, shell command nesting within templates, cross-provider load balancing/variants, SSH integration.
