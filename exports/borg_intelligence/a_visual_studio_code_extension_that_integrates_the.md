## 🧠 Technical Summary
The opencode-custom-port-plugin acts as a bridge between the opencode CLI-based AI assistant and the Visual Studio Code IDE. It focuses on reducing friction in the developer workflow by automating terminal session management and context injection. Technically, it handles VS Code terminal creation, monitors editor selection states to share context with the CLI, and implements a port management system that allows users to define static ports or use an automated range. It specifically includes logic for Windows to detect and terminate conflicting processes on the target port before initializing the opencode server.

## 🛠️ Key Features
Split terminal integration, Hotkey-based session launching, Context-aware selection sharing, Automated file reference insertion (@File syntax), Custom port assignment (1024-65535), Automatic port conflict resolution
