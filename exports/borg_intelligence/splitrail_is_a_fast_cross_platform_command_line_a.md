# Splitrail is a fast, cross-platform command-line and VS Code tool for real-time tracking and monitoring of token usage and associated costs across various AI coding assistants.

## 🧠 Technical Summary
Splitrail functions primarily as a developer-facing monitoring tool, providing visibility into how much various large language model (LLM) powered tools (like Gemini CLI, Copilot, Claude Code, etc.) are being used. It captures usage data, displays real-time statistics via CLI or a VS Code extension, and offers optional cloud upload for aggregation. Furthermore, it includes an MCP (Model Context Protocol) server mode allowing other AI assistants to programmatically query usage statistics, which integrates usage monitoring directly into the development workflow.

## 🛠️ Key Features
Real-time token usage tracking, Cross-platform CLI tool, VS Code extension integration, Cost monitoring capabilities, MCP server for programmatic querying, Usage aggregation via Splitrail Cloud.
