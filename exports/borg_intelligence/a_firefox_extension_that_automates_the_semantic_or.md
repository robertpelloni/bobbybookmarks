## 🧠 Technical Summary
This extension transforms browser bookmarks into a structured knowledge base by leveraging the OpenAI API for semantic analysis. It processes individual bookmarked URLs by generating 500-word summaries and corresponding vector embeddings for each page. The system then applies hierarchical clustering to these embeddings to identify latent topical relationships, grouping similar bookmarks into dynamically generated cluster folders. This approach replaces manual folder management with an automated, semantically-aware persistence layer for personal web data.

## 🛠️ Key Features
Automated vector embedding of browser links, hierarchical clustering for data organization, LLM-based folder naming, automated page summarization, semantic grouping of persisted knowledge
