## 🧠 Technical Summary
Probe bridges the gap between raw text search (grep) and vector-based RAG by utilizing Tree-sitter for AST parsing and ripgrep for speed. It allows AI agents to query codebases using boolean logic to retrieve entire functions or classes rather than fragmented text lines or arbitrary vector chunks. The system eliminates the need for pre-indexing or external embedding models, instead relying on the LLM to translate intent into precise structural queries. Key technical features include session-based deduplication to prevent context window bloat and token-budget management to ensure retrieved context remains within model limits.

## 🛠️ Key Features
