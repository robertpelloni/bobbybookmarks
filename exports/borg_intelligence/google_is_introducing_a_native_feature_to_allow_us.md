# Google is introducing a native feature to allow users to change their primary '@gmail.com' addresses while maintaining the original address as a persistent functional alias.

## 🧠 Technical Summary
This update represents a major shift in Google's identity management infrastructure, decoupling the primary user identifier from the fixed account creation string. The technical implementation involves converting the original Gmail address into a permanent alias that continues to support incoming mail routing and authentication. Data persistence is maintained across the transition, ensuring that Drive, Photos, and Calendar events remain linked to the underlying account GUID despite the change in public-facing email address. To prevent abuse, Google has implemented constraints including a 12-month cooldown period and a lifetime limit of three address changes per account.

Identity aliasing, seamless data persistence, legacy sign-in support, multi-address inbox routing, rate-limiting cooldowns, account identifier rotation, backward compatibility for calendar events
