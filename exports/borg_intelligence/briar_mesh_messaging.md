## 🧠 Technical Summary
A peer-to-peer mesh messaging system that uses Bluetooth, Wi-Fi, and Tor to synchronize data without central servers, featuring Delay-Tolerant Networking (DTN).

## 🛠️ Key Features
Multi-transport sync (BT/Wi-Fi/Tor), store-and-forward Delay-Tolerant Networking, Bramble protocol suite, encrypted ad-hoc mesh networking.
