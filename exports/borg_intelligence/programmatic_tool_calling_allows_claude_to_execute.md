# Programmatic tool calling allows Claude to execute logic within a sandboxed container to invoke tools, significantly reducing latency and token consumption in complex, multi-step workflows.

## 🧠 Technical Summary
Programmatic tool calling is a workflow optimization technique where the Claude model generates Python code that directly calls defined tools within a dedicated code execution container. This circumvents the traditional round-trip latency and context bloat associated with invoking tools one by one through the API. Key to this feature is the `allowed_callers` field in tool definitions, which dictates whether a tool can be called directly by the model or only from within the code execution environment (specified using `code_execution_20260120`). The execution flow involves Claude writing script logic, pausing for tool results, resuming processing within the container, and only returning the final, filtered result to the main context window. This is essential for large data processing, conditional logic based on intermediate results, and accelerating multi-step agentic benchmarks.

## 🛠️ Key Features
In-container programmatic tool invocation, Latency reduction for multi-tool workflows, Reduced context window consumption via intermediate data filtering, Conditional logic support within agent execution flow, Asynchronous tool invocation support via generated Python code (using await), Explicit control over tool invocation context via 'allowed_callers'
