## 🧠 Technical Summary
Emdash functions as a specialized 'IDE for Agents,' designed to solve the orchestration and isolation challenges of running various CLI-based AI coding agents. Technically, it leverages Git worktrees to create isolated ephemeral environments for each agent session, preventing file conflicts and allowing for clean diff reviews before merging. It acts as a provider-agnostic wrapper for over 20 different CLI agents (e.g., Claude Code, Qwen, Goose), abstracting their specific installation and execution requirements into a consistent UI. The architecture supports local-first development with a SQLite backend while offering robust remote development capabilities via SSH/SFTP, integrating directly with project management tools like Linear, GitHub, and Jira to automate the ticket-to-PR pipeline.

## 🛠️ Key Features
Multi-agent parallel execution, Git worktree isolation, provider-agnostic CLI integration, SSH/SFTP remote development support, integrated issue-to-agent workflow, local-first SQLite state management, OS keychain credential storage, automated PR and CI/CD status monitoring
