## 🧠 Technical Summary
The opencode-plugin-simple-memory project provides a standardized interface for AI agents to interact with long-term storage via five core tools: remember, recall, update, forget, and list. It employs a decentralized, file-based approach where memories are stored in '.opencode/memory/' as daily logfmt files, ensuring data remains human-readable and local. The architecture distinguishes between memory scopes (e.g., user vs. project) and specific types such as decisions, learning, and blockers, allowing for targeted context retrieval without the overhead of a dedicated vector database. It includes built-in audit logging for deletions and supports a manual cache-clearing workflow for plugin updates.

## 🛠️ Key Features
Tool-based memory management, Categorized memory types (decision/learning/preference), Scope-based retrieval, Daily logfmt file storage, Audit-logged deletions, Local-first data ownership, Keyword/Metadata search
