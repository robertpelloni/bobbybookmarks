# This tool acts as a proxy to route requests originating from the Google Gemini CLI to various OpenAI-compatible LLM APIs.

## 🧠 Technical Summary
The 'gemini-cli-router' is a client-side utility implemented in JavaScript that intercepts calls intended for the Gemini CLI agent and redirects them. It achieves this by transforming the request format expected by the Gemini CLI (or routing the command execution via the `GEMINI_CLI_PATH` environment variable) into the format required by OpenAI-compatible endpoints, such as standard OpenAI, Azure OpenAI, or OpenRouter. The configuration allows users to define multiple backend providers with specific authentication (API keys, base URLs, deployment names) and select a default. It features request/response transformation logic (`transformToOpenAI.js`, `transformToGemini.js`) and an optional passthrough mode for pure logging, making it a lightweight interoperability layer.

## 🛠️ Key Features
Proxy routing, Multi-provider configuration, OpenAI compatibility shim, Request/Response logging, Custom Gemini CLI path specification
