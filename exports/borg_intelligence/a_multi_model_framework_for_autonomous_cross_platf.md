## 🧠 Technical Summary
ClickClickClick implements a modular agentic architecture consisting of three primary components: the Planner, the Finder, and the Executor. The Planner decomposes natural language prompts into high-level steps; the Finder leverages vision-capable LLMs (such as GPT-4o, Gemini, or Llama 3.2) to perform UI element detection and coordinate identification; and the Executor translates these coordinates into system-level inputs using tools like ADB for Android or native OS hooks for OSX. This separation allows for hybrid configurations, such as using a powerful remote model for reasoning while employing local models via Ollama for vision processing, effectively managing the trade-off between latency, cost, and privacy.

## 🛠️ Key Features
Planner-Finder-Executor architecture, multi-platform support (Android and OSX), local LLM support via Ollama, vision-based UI element detection, configurable image quality for latency optimization, REST and CLI interfaces, ADB integration for mobile automation, hybrid remote/local model configurations.
