## 🧠 Technical Summary
An open-source persistent memory layer for LLMs that categorizes information into Semantic, Episodic, and Procedural layers, mirroring human memory architectures.

## 🛠️ Key Features
Semantic (facts), Episodic (events/context), and Procedural (workflows) memory layers, automated entity/relationship extraction, "cognitive profile" generation.
