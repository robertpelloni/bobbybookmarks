## 🧠 Technical Summary
Bilgecan provides a robust, Java-based infrastructure for executing LLM workloads locally by leveraging Spring AI to interface with Ollama and PostgreSQL (pgvector). The platform's technical core is its ability to handle long-running, asynchronous AI tasks—such as batch document analysis and report generation—outside of a standard chat loop. It features a unique file processing pipeline that monitors specific root directories (input, output, archive, upload) to automate AI workflows across large datasets. Built with Vaadin, it offers a 100% Java-based frontend that manages workspace collaboration, allowing teams to share prompts and task configurations while maintaining data sovereignty through local inference.

## 🛠️ Key Features
Asynchronous task execution, directory-based file processing pipelines, RAG with pgvector, Vaadin-based Java UI, workspace-based collaboration, Ollama integration, vision model support, automated document analysis
