## 🧠 Technical Summary
An intelligent proxy server (Go) that allows users to hot-swap local LLMs on demand, automatically managing the lifecycle of inference servers like vLLM or llama.cpp.

## 🛠️ Key Features
Automatic inference server hot-swapping, OpenAI/Anthropic API compatibility, Time-To-Live (TTL) model unloading, "Groups" for multi-model concurrent running.
