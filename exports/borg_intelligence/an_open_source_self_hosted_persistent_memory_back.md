## 🧠 Technical Summary
mcp-memory-service provides a dedicated, persistent memory layer for multi-agent systems (like LangGraph, CrewAI, AutoGen) that aims to solve context loss and the need to re-explain project context in every session. It operates as a self-hosted RESTful service that stores memories, decisions, and causal relationships within a knowledge graph structure. Key architectural features include local ONNX embedding generation for privacy, autonomous consolidation of old memories to manage context size, and specialized tagging mechanisms (like X-Agent-ID and sentinel tags) for scoped retrieval and inter-agent communication. It supports a unique 'Remote MCP' setup allowing direct integration with browser-based LLM interfaces like claude.ai.

## 🛠️ Key Features
REST API for memory storage and retrieval, Knowledge graph structure with typed edges (causal relationships), Autonomous memory consolidation/compression, Local ONNX embedding generation, Agent-scoped memory retrieval via X-Agent-ID header, Support for Remote MCP (browser-based LLM integration), SSE events for real-time memory updates
