## 🧠 Technical Summary
Agent Skills is a standardized, folder-based format for defining reusable capabilities, comprised of instructions, scripts, and resources. This system allows agents to load specific procedural knowledge (domain expertise, repeatable workflows, new capabilities) contextually, extending their functionality without permanent modification. It serves as a mechanism for on-demand capability extension and workflow encapsulation, enabling interoperability across different skills-compatible agent products.

## 🛠️ Key Features
Folder-based skill packaging, On-demand skill loading, Procedural knowledge encapsulation, Support for instructions and scripts, Open standard for capability sharing, Version-controlled packages for organizational knowledge capture.
