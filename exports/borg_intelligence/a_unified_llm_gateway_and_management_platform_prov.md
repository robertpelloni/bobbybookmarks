## 🧠 Technical Summary
Anannas acts as a centralized infrastructure proxy that abstracts various LLM provider APIs into a single, OpenAI-compatible interface. It focuses on the operational layer of AI integration by offering real-time observability into token consumption, cost per model, and request frequency. The platform allows developers to bypass the need for multiple client libraries while providing a dashboard for granular tracking of API calls, spend optimization, and activity logging across different organizational projects.

## 🛠️ Key Features
Unified OpenAI-compatible API, real-time token tracking, spend monitoring and budgeting, request logging and auditing, multi-provider model aggregation, usage analytics dashboard, API key management
