# A lightweight library that implements a feedback-driven memory loop to refine LLM agent prompts through vector retrieval of past user corrections.

## 🧠 Technical Summary
The project implements a retrieval-augmented self-improvement cycle for LLM agents by treating user feedback as a persistent memory layer. It utilizes an embedding layer—supporting both OpenAI and HuggingFace models—to vectorize specific tasks and their associated user feedback. When a similar task is encountered, the system performs a similarity search against a local JSON-based storage to identify relevant historical feedback. This feedback is then dynamically injected into the system prompt to guide the LLM toward better performance. A key technical feature is the inclusion of an 'LLM-based selection layer' that evaluates the retrieved feedback for relevance before augmentation, ensuring that only contextually appropriate corrections influence the agent's behavior.

## 🛠️ Key Features
Feedback-to-embedding mapping, Local-first JSON vector storage, LLM-driven feedback relevance filtering, Contextual prompt augmentation, Asynchronous feedback processing, Multi-provider embedding support (OpenAI/HuggingFace), Framework-agnostic integration
