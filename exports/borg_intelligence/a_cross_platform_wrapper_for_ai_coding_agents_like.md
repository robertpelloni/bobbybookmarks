## 🧠 Technical Summary
Happy functions as a sophisticated proxy layer for CLI-based AI coding agents, specifically targeting tools like Claude Code and Codex. It synchronizes terminal session states across local CLI, a centralized encrypted relay server, and mobile/web clients using a custom signaling protocol. The architecture enables 'instant device switching,' allowing a developer to pause a local terminal session and resume it via a mobile app while away from their desk. Security is maintained through end-to-end encryption (E2EE), ensuring the relay server acts only as a conduit for encrypted data, while features like push notifications for agent permission prompts solve the 'headless' execution bottleneck.

## 🛠️ Key Features
Mobile remote control for CLI agents, E2EE session synchronization, seamless CLI-to-mobile hand-off, push notifications for agent prompts, integrated real-time voice interface, multi-platform state persistence, open-source relay server
