## 🧠 Technical Summary
Conductor acts as a proactive project manager within the Gemini CLI environment, focusing on structured workflow control. It enforces a 'Context -> Spec & Plan -> Implement' lifecycle. Setup involves defining persistent project context artifacts (product, guidelines, tech stack, workflow) which govern subsequent agent interactions. New work is initiated via 'tracks' with detailed specs and actionable plans. The core orchestration is performed by the `/conductor:implement` command, which iterates through plan tasks, potentially following a TDD workflow, and requires manual verification at phase boundaries. It also provides utility commands for status tracking and git-aware reverting based on logical work units.

## 🛠️ Key Features
Context definition setup, Specification and Plan generation for tracks, Agent-driven implementation following a plan, Git-aware logical unit reverting, Workflow enforcement (e.g., TDD), Status tracking.
