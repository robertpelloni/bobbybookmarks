## 🧠 Technical Summary
AgentDepot-Agents acts as a centralized data layer for AgentDepot.dev, providing a structured repository of AI agent configurations tailored for specific environments like Cursor, Windsurf, Claude Code, and Replit. The project utilizes a TypeScript-defined schema to normalize metadata across different tools, including installation instructions, agent types (rules, plugins, skills), and categorization. It employs a Git-based contribution workflow where submissions are validated via automated GitHub Actions for schema compliance, duplicate detection, and compilation, ensuring a high-quality, interoperable set of instructions for developers to optimize their AI pair-programming experience.

## 🛠️ Key Features
Standardized agent metadata schema, cross-IDE compatibility (Cursor, Windsurf, Replit), MCP tool integration, automated CI schema validation, community-curated registry, structured 'system rule' templates, automated production sync.
