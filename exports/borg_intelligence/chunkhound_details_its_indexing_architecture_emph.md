## 🧠 Technical Summary
ChunkHound utilizes a multi-stage indexing process designed for performance, especially with large codebases. Initial indexing creates a comprehensive knowledge base, which subsequent updates modify incrementally, preserving embeddings for unchanged code via 'Smart Diffing'. It supports real-time updates when used with its Multi-Chunk Processing (MCP) server, automatically re-indexing only changed files upon edits or branch switches. Deployment modes include 'stdio' (IDE-managed in-memory) for personal use and 'HTTP' for shared, persistent server deployment, highlighting that the performance bottleneck is often the embedding provider, not the indexing hardware.
