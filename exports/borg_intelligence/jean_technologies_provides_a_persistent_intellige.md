## 🧠 Technical Summary
Jean Technologies focuses on building the foundational memory and representation layer for AI applications. Their core offering, Jean Memory, handles the ingestion of raw user data (conversations, enrichment, activity) and compiles it into persistent, context-rich memory structures. This memory is then used to power personalization, AI agents, and sophisticated matching systems by creating high-fidelity representations. A secondary offering, Domain Embeddings, customizes embedding models using the compiled memory data to predict real-world outcomes specific to the user's domain.

## 🛠️ Key Features
