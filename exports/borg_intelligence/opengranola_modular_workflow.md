## 🧠 Technical Summary
A lightweight, open-source framework for building modular AI workflows using declarative configurations (POML) optimized for rapid prototyping.

## 🛠️ Key Features
Declarative Prompt Orchestration Markup Language (POML), decoupled infrastructure components, native integration with Kreuzberg (document analysis) and Kodus (code review).
