## 🧠 Technical Summary
An open-source peer-to-peer framework developed by the Cult of the Dead Cow (cDc) for high-performance privacy-first application routing.

## 🛠️ Key Features
256-bit public key identifiers, multi-protocol transport (UDP/TCP/WS), network-switching resilience, upgradable cryptography, no-token architecture.
