## 🧠 Technical Summary
AI-AfterImage functions as a local, session-to-session memory layer for AI coding agents, specifically targeting Claude Code. It operates via a hook system that intercepts 'Write' and 'Edit' actions. Before writing, it searches a local Knowledge Base (KB) built on SQLite (or optional PostgreSQL/pgvector) for semantically similar past code and injects this context into the prompt. After writing, it extracts the resulting diff and stores it in the KB. Key architectural components include hybrid search (keyword + semantic), semantic chunking for intelligent context retrieval (using AST parsing via tree-sitter for Code Intelligence), and code churn tracking based on modification frequency and file stability tiers (Gold, Silver, Bronze, Red). The system emphasizes local operation, requiring no external APIs after initial model download, and supports offline use.

## 🛠️ Key Features
Local SQLite/PostgreSQL KB, Hybrid Search (Keyword + Semantic), Pre-write Context Injection, Post-write Diff Extraction/Storage, Code Intelligence (AST Parsing, Language Detection), Semantic Chunking, Code Churn Tracking with Tiering, CLI management.
