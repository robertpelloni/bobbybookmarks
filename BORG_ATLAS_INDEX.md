## Signal Strength (⚡)

The **Signal** metric (0-100) answers: *"Is this tool actually worth my time?"*

| Component | Weight | What it measures |
|-----------|--------|------------------|
| Innovation × 4 | 0-40 | Raw innovation score from LLM analysis |
| Quality × 30 | 0-30 | Computed from description depth, feature count, tags |
| Feature richness | 0-15 | How many concrete features are listed |
| Description depth | 0-10 | How detailed the description is |
| GitHub trust | 0-5 | Small bonus for being an open-source repo |

### Signal thresholds

| Range | Meaning |
|-------|----------|
| ⚡85+ | 🏆 Must-know — world-class tools |
| ⚡70-84 | ⭐ Excellent — highly recommended |
| ⚡50-69 | ✓ Solid — worth exploring |
| ⚡30-49 | ○ Adequate — has useful features |
| ⚡0-29 | ⚠ Thin — limited data available |
